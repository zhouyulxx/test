- A uses native repeated-image DCAE-V reference initialization. B/C are encoded with DCAE-V, then their last latent image is used as a target. CPU cache holds at most eight references.
- Soft correction operates on the last four latent positions after Euler steps. Alpha is strength/steps times (1-sigma) times a squared temporal ramp. Target is noise-level matched. Corrected latents enter cache continuation. This is an UNTRAINED inference heuristic, not a learned pose/geometric correction mechanism; ghosting or blur are possible.
